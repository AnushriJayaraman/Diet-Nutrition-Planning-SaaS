# Diet and Nutrition Planning SaaS for Clinic

## Project Overview
Diet and Nutrition Planning SaaS for Clinic is a web-based application that helps clinics manage patient records, create personalized diet plans, schedule appointments, and track nutrition progress efficiently.

## Features
- User Login
- Patient Management
- Diet Plan Management
- Appointment Management
- Nutrition Reports
- Dashboard

## Target Users
- Admin
- Dietitian
- Clinic Staff
- Patient

## Technology Stack
- Java
- Spring Boot
- MySQL
- Maven
- Git
- GitHub
