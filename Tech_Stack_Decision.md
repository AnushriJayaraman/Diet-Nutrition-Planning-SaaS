# Requirement Analysis

## Functional Requirements

1. User Registration and Login
   - Admin and Dietitian login.
   - Secure authentication.

2. Patient Management
   - Add patient details.
   - Update patient records.
   - Delete patient records.
   - View patient information.

3. Diet Plan Management
   - Create personalized diet plans.
   - Update diet plans.
   - Assign diet plans to patients.

4. Appointment Management
   - Schedule appointments.
   - Update appointment dates.
   - Cancel appointments.

5. Nutrition Progress Tracking
   - Record patient progress.
   - View progress history.

## Non-Functional Requirements

- User-friendly interface.
- Secure data storage.
- Fast response time.
- Reliable system availability.
- Easy maintenance.
- Scalable architecture.

## Software Requirements

- Java 21
- Spring Boot
- Maven
- MySQL
- VS Code / IntelliJ IDEA
- Git & GitHub

## Hardware Requirements

- Windows 10/11
- Minimum 8 GB RAM
- Intel i3 or above
- Internet Connection
