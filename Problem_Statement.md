# Problem Statement

## 1. Project Title
Diet and Nutrition Planning SaaS for Clinic

## 2. Domain
Healthcare

## 3. Problem Statement
Many clinics still use paper records or spreadsheets to manage patient diet plans, appointments, and nutrition records. This makes it difficult to organize data, update diet plans, and track patient progress efficiently.

## 4. Proposed Solution
Develop a SaaS-based web application that helps clinics manage patient records, create personalized diet plans, schedule appointments, and monitor nutrition progress in one centralized system.

## 5. Target Users
- Admin
- Dietitian
- Clinic Staff
- Patients

## 6. Objectives
- Manage patient information digitally.
- Create and update personalized diet plans.
- Schedule and manage appointments.
- Track patient nutrition progress.
- Generate reports for better decision-making.

## 7. Core Features
- Secure Login
- Patient Management
- Diet Plan Management
- Appointment Management
- Nutrition Reports
- Dashboard

## 8. Database Tables
- Users
- Patients
- Diet_Plans
- Appointments
- Nutrition_Reports
- Food_Items

## 9. User Roles
### Admin
- Manage users
- View reports
- Monitor the system

### Dietitian
- Manage patients
- Create diet plans
- Track progress

### Patient
- View diet plans
- View appointments
- Check nutrition progress

## 10. Success Criteria
- Easy patient record management
- Quick diet plan creation
- Better appointment scheduling
- Accurate nutrition tracking

## 11. Out of Scope
- Online payment
- Video consultation
- Medicine delivery

## 12. Technology Stack
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
